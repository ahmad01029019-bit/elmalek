# ElMalek

اريد بناء منصة تعليمية للطلاب من المرحلة الاعدادية للثانوية للعام والازهر واللغات وجميع الشعوب ادبي وعلمي ولغات كما اريدها متوافقة على جميع الاجهزة اريد بها رئيسية قبل الدخول بها نبذة تعريفية وبعض الكورسات المجانية وبعد انشاء الحساب او تسجيل الدخول ينتقل الطالب الى حسابه بمعلوماته ويكون هناك قائمة جانبية بها صفحاته مثل سلة الكورسات والمحفظة والمواد الدراسية والرئيسية وكمان الاحصائيات والسجل الدراسي وقسم اسمه مكتبة الملك فيها كتب الكترونية كانها اختبارات بفيديوهات حل فكرة المنصة هي تجميع محتوى اليتيوب عبر التضمن ووضعه في كورسات كاملة منظمة مع متابعة وتصحيح تلقائي وميزة الذكاء لتصحيح الاسئلة المقالية يعني من صفحة الادارة هيكون فيه خيارات اني انشئ لكل معلم صفحته الخاصة واضيفله فيها الكورسات بتاعته وتحديد سعر الكورس واضافة فيديوهات ملفات واختبارات الكترونية بتصحيح تلقائي وملحوظات بعد التصحيح لكل سؤال مع وقت واستكمال لاحقا وغيره من باقي صفحات المنصة التعليمية واريد ايضا في الرئيسية قبل الدخول زي زر كدا للمسوقين مربوطة بالكورسات المسوق يعمل حسابه ويعمل كود خصم بنسبة محددة وياخد نسبة على كل عملية شراء بهذا الكود بعد تخطيه عدد 100 طالب في البداية شروط الربح وسحب الربح عن طريق بوابة الدفع كما سيكون هناك باقي الصفحات الاساسية من سياسة الخصوصية وغيره والرؤية والرسالة وغيره
