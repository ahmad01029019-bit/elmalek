# منصة تعليمية عربية (RTL) — خطة البناء

منصة لتجميع محتوى يوتيوب داخل كورسات منظمة، مع اختبارات وتصحيح تلقائي، ومكتبة إلكترونية، ونظام مسوقين — بإدارة مركزية من طرفك أنت فقط.

## الهوية والتجربة
- عربية بالكامل باتجاه RTL، خط عربي واضح (Cairo/Tajawal).
- طابع أكاديمي هادئ: أزرق/أبيض، تباين مريح، بطاقات نظيفة.
- متجاوبة بالكامل: موبايل أولاً، ثم تابلت وديسكتوب.

## المرحلة 1 — الواجهة العامة (قبل الدخول)
- الرئيسية: نبذة تعريفية، المراحل المدعومة (إعدادي/ثانوي — عام وأزهري ولغات، علمي وأدبي)، كورسات مجانية، شهادات/مميزات، دعوة للتسجيل.
- زر بارز "انضم كمسوّق" يشرح شروط الربح (عمولة بعد تجاوز 100 طالب) ويقود لتسجيل حساب مسوّق.
- صفحات ثابتة: من نحن، الرؤية والرسالة، الأسئلة الشائعة، تواصل معنا، سياسة الخصوصية، الشروط والأحكام.
- صفحة معلّم عامة (تعرض بياناته وكورساته)، وصفحة تفاصيل كورس.
- تسجيل حساب / دخول (بريد وكلمة مرور) مع ملف طالب (الاسم، المرحلة، الشعبة، النوع: عام/أزهري/لغات).

## المرحلة 2 — حساب الطالب
قائمة جانبية قابلة للطي (تعمل كقائمة سفلية/منزلقة على الموبايل):
- الرئيسية: ملخص التقدم وآخر نشاط.
- المواد الدراسية: كورساتي والدروس والفيديوهات والملفات.
- سلة الكورسات: إضافة/حذف، تطبيق كود خصم، إتمام الشراء (محاكاة).
- المحفظة: الرصيد، عمليات الشحن والشراء (محاكاة الآن).
- الإحصائيات: نسب الإنجاز، متوسط الدرجات، وقت المذاكرة.
- السجل الدراسي: كل الاختبارات ودرجاتها وملاحظات التصحيح.
- مكتبة الملك: كتب إلكترونية على شكل اختبارات مع فيديوهات حل.

### تشغيل الدروس والاختبارات
- تضمين فيديوهات يوتيوب داخل مشغل الدرس مع تتبع الإكمال.
- اختبارات: اختيار من متعدد وصح/خطأ (تصحيح تلقائي فوري) + أسئلة مقالية.
- مؤقّت للاختبار، حفظ تلقائي، و"استكمال لاحقًا" من نفس النقطة.
- ملاحظة تصحيح لكل سؤال تظهر بعد التسليم.

## المرحلة 3 — لوحة الإدارة (أنت فقط)
لا توجد لوحة دخول للمعلمين؛ كل شيء يُدار من الإدارة:
- إدارة المعلمين: إنشاء معلم + صفحته العامة (صورة، نبذة، المواد والصفوف).
- إدارة الكورسات: ربط الكورس بمعلم + مرحلة + شعبة + نوع تعليم، تحديد السعر أو مجاني.
- بناء محتوى الكورس: أقسام ودروس، روابط يوتيوب، ملفات PDF، اختبارات وبنك أسئلة مع الإجابات والملاحظات.
- إدارة مكتبة الملك: الكتب وفيديوهات الحل.
- إدارة الطلاب: العرض، التفعيل، شحن المحفظة يدويًا، منح كورس.
- إدارة المسوقين: اعتماد الحسابات، أكواد الخصم ونِسبها، متابعة عدد المشتركين، طلبات السحب.
- إعدادات المنصة ومحتوى الصفحات الثابتة.

## المرحلة 4 — المسوّقون
- تسجيل مسوّق واعتماد من الإدارة.
- إنشاء كود خصم بنسبة محددة مرتبط بكورس أو بكل الكورسات.
- لوحة المسوّق: عدد الاستخدامات، الطلاب، الأرباح المستحقة، شريط تقدّم حتى 100 طالب، طلب سحب (محاكاة).

## المرحلة 5 — التصحيح الذكي
- تصحيح الأسئلة المقالية عبر الذكاء الاصطناعي المدمج في Lovable AI: درجة مقترحة + ملاحظة عربية لكل إجابة، مع إمكانية تعديل الدرجة من الإدارة.

## التفاصيل التقنية
- TanStack Start + React + Tailwind v4، توكنات ألوان دلالية في `src/styles.css`، اتجاه RTL على مستوى الجذر.
- تفعيل Lovable Cloud للقاعدة والمصادقة والتخزين.
- الجداول الأساسية: `profiles`, `user_roles` (admin/student/marketer)، `teachers`, `courses`, `sections`, `lessons`, `attachments`, `quizzes`, `questions`, `quiz_attempts`, `attempt_answers`, `enrollments`, `cart_items`, `wallet_transactions`, `library_books`, `book_videos`, `marketers`, `promo_codes`, `referrals`, `payouts`, `site_pages`.
- RLS على كل الجداول: الطالب يقرأ بياناته فقط، قراءة عامة محدودة للكورسات والمعلمين، والإدارة عبر دالة `has_role` آمنة.
- منطق الخادم عبر `createServerFn` (شراء، بدء/تسليم اختبار، تطبيق كود خصم، التصحيح الذكي) — لا تُحتسب الدرجات في المتصفح.
- الدفع محاكاة الآن: عمليات محفظة داخلية بدون بوابة حقيقية، وقابلة للاستبدال ببوابة لاحقًا.
- SEO: عنوان ووصف ووسوم مشاركة خاصة بكل صفحة عامة.

## طريقة التنفيذ
سأبني المراحل بالترتيب: (1) الواجهة العامة والتسجيل، (2) حساب الطالب والمشغل والاختبارات، (3) لوحة الإدارة، (4) المسوقين، (5) التصحيح الذكي — مع مراجعتك بعد كل مرحلة.
